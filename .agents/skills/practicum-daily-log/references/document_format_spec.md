# 东华理工大学《实习日志》模板原生规范

本文档严格对齐 `docs/templates/实习日志.doc` 原文。

**重要说明**：封面与表头中的个人和企业信息**严禁在代码或模板中硬编码**，必须严格从当前 Skill 目录下的环境变量文件 `.practicum.env` 中动态读取注入。

---

## 一、 封面（首页）

* **顶部校标**：东华理工大学标准组合标识（引用本 Skill 资源：`assets/ecut_logo.png`）。
* **主标题**：居中大号黑体加粗——**《生产实习》报告**
* **基本信息字段**（四号宋体，加粗，**全部由 `.practicum.env` 动态注入**）：
  * **题　　目：** `${PRACTICUM_TOPIC}`（根据实训课题指定，未指定时留空供手填）
  * **学　　号：** `${PRACTICUM_STUDENT_ID}`
  * **姓　　名：** `${PRACTICUM_STUDENT_NAME}`
  * **专　　业：** `${PRACTICUM_MAJOR}`
  * **班　　级：** `${PRACTICUM_CLASS}`
  * **企业指导教师：** `${PRACTICUM_ENTERPRISE_MENTOR}（${PRACTICUM_ENTERPRISE_NAME}）`
  * **学校指导教师：** `${PRACTICUM_SCHOOL_MENTORS}`
  * **实习时间：** `${PRACTICUM_START_DATE}——${PRACTICUM_END_DATE}`
* **底部日期**：居中偏右——当前归档年月（格式：`YYYY年MM月`，从 `${PRACTICUM_START_DATE}` 或当前日期提炼）。

## 二、 结构精简铁律 (严禁将说明指南写入正式交付物)

* **重要规则**：原模板中的“实习报告撰写提纲”与“实习报告格式要求”仅为给学生参考的指导指南（Meta Spec），**严禁将这两段指导文字打印或写入正式提交的 Word 日志文档中**！
* **页面逻辑**：封面页后插入分页符，**直接且立即进入《实习日志》主体表格**，杜绝任何中间冗余页面。

## 四、 格式要求 (仅作为排版参数准绳，不入正文)

1. **页面设置（边距）**：上下边距 `2.54cm`，左 `3.00cm`，右 `2.00cm`；
2. **字体规范**：
   * 一级标题：常用四号宋体，加粗；
   * 二级及以下标题：小四号宋体，加粗；
   * 正文：小四号宋体；
   * 非汉字字符（英文字母、数字、代码等）：使用 **Times New Roman** 字体；
3. **行距与缩进**：
   * 行距：**1.25 倍行距**；
   * 段落首行缩进：**2 个汉字字符**；
4. **目录**：自动生成；
5. **参考文献**：遵循国家标准 **GB/T 7714《信息与文献 参考文献著录规则》**。

---

## 五、 每日《实习日志》表格规范

* **表头字段（严格由 `.practicum.env` 动态填充）**：
  * **学号**：`${PRACTICUM_STUDENT_ID}`
  * **姓名**：`${PRACTICUM_STUDENT_NAME}`
  * **班级**：`${PRACTICUM_CLASS}`
  * **专业**：`${PRACTICUM_MAJOR}`
  * **实习企业**：`${PRACTICUM_ENTERPRISE_NAME}`
  * **实习时间**：`${PRACTICUM_START_DATE} 至 ${PRACTICUM_END_DATE}`
* **表格交替单列结构**：
  * **单元格 1（窄行）**：`日期：YYYY年MM月DD日`
  * **单元格 2（内容区）**：`实习记录:`
    * 第一人称叙述（以 `${PRACTICUM_STUDENT_NAME}` 为第一视角）：记录当天的实操活动、关键配置、遇到的问题与解决、以及成果截图（Cua 抓取的高清 Web UI / 终端输出）。
