# 日志语言与事实规范

用学生自己的朴素口吻写清当天学了什么、做了什么、结果如何。默认单日正文 200–300 字，用户或模板另有要求时按其要求。

- 使用具体命令、参数、操作和可观察结果；删掉能套用到任何课程的空话。
- 区分老师演示、用户提供的经历与本次实际复现；只把有来源的内容写成完成事实。
- 有真实报错才写排查过程。没有问题可写“本次未遇到明显问题”，不要为了像学生而编造乱码、端口冲突等小插曲。
- 不写“深刻理解”“夯实基础”等评价或强行升华结尾。心得可落到实际收获或下一步操作。

默认条目覆盖：今日学习与任务、动手操作过程、遇到的小问题与解决、实操结果截图、今日心得。图片只使用真实证据；缺失内容明确标记待补，不把固定板块当作编造材料的理由。

示例：有对应证据时可写“Java 8 下执行 java --version 报错，改用 java -version 后确认了版本”；不能仅因为这是常见问题就写进当天日志。
