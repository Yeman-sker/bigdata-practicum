## 目标与范围

用户是共享单车运营人员：看清当前库存、对照历史供需、识别一小时后风险，并查看可行的调度建议。7 天从项目 Day 1 起算，最低真实验收数据为 2025-01 全部 CSV 加 GBFS 快照；页面日期来自已发布数据。

P0 为实时地图、单日历史 OD 回放、站点历史分析、未来一小时风险、调度建议。P1 仅为五个运营 KPI，Day 6 在 P0 稳定后决定是否加入。不做登录、AI/ML、天气、VRP、司机执行流程、逐车 GPS、逐笔实时骑行事件或全年扩数。

## 页面与五条使用路径

```text
┌────────────────── 全屏地图 ──────────────────┐
│ [搜索] [实时/回放] [地图视角]        [来源 · 时间 · 状态] │
│                                                │
│      库存粒子 / 风险光晕 / 调度或历史流向       │
│             ○ 站点地图透镜（按需）              │
│                                                │
│       [日期 · 小时 · 播放 · 倍速]（回放时按需）  │
└──────────────────────────────────────────────┘
```

| 路径 | 用户操作 → 数据需求 → 可见结果 | 空或异常 |
| --- | --- | --- |
| 实时态势 | 打开首页 → live map → 黄色粒子、当前状态光晕、空间巡览 | 没有成功快照显示尚无数据；失败、过期分别提示 |
| 一小时风险 | 从地图视角拨盘切换风险口径 → 复用 map 响应 → 光晕切为预测 | 无基线显示数据不足，保留有效当前库存 |
| 调度 | 切到调度视角 → 同批 suggestions → Top 5 方向线突出、其余建议可巡览；点击查看数量、距离及依据 | 无可行建议显示空态，不编造配对 |
| 历史回放 | 选可用日期、小时，播放或拖动 → replay map → 非零 OD 流向 | 无流量与未知日期分别处理 |
| 站点分析 | 点击站点或从搜索/空间巡览定位 → 站点地图透镜 + station history → 24 小时供需、sample_days | 无基线与无当日活动分别显示；历史下线站点仍可查询 |

## 实时模式

- 黄色粒子群始终表示最新实际可用车辆数，站点锚定、轻微分散；数量图例应可解释。粒子不表示真实车辆坐标。
- 光晕默认使用当前库存状态，可切换未来一小时风险。切换只改变光晕，粒子仍表示实际库存。
- 风险空间巡览：SHORTAGE_RISK/OVERFLOW_RISK 优先，LOW_INVENTORY/HIGH_INVENTORY 其次；每类按 station_id 字符串升序。异常随后按 SERVICE_UNAVAILABLE、STALE_DATA、INVALID_DATA、INSUFFICIENT_DATA，再按 station_id 排序。健康站点不进入巡览序列。
- 点击站点或用搜索/键盘巡览定位并打开同一地图透镜；无坐标仍打开详情，说明无法定位。详情同时显示当前与预测、观测时间、预测目标时间、基线样本数；前端只解释字段，不重新计算规则。
- 60 秒刷新一次 live map；无新快照也按 expires_at_utc 更新有效性。刷新失败保留最近成功结果并提示；超过有效期后暂停预测与调度展示。恢复后台标签页时立即刷新。
- 数据过期或非法时，不把旧库存画成有效当前库存；可在详情以“上次观测”及时间显示。负库存不画负数粒子或改成零。新鲜数据确认停服时显示服务不可用，暂停预测与涉及该站的调度。

## 调度与当前告警

调度采用“预测决定需求、当前状态约束可行性”，详见 [规则契约](contracts/operations.md)。同批输入只有一套建议，不随风险视图切换改变。当前缺车但预计自然回升时，保留当前告警；当前正常但预计缺车时，可以产生预防性补车建议。

地图突出排序前 5 条建议，静态方向线指向补车站，线宽按数量分级。调度视角以低透明度保留其他建议，允许指针或键盘逐条巡览；选中后突出方向线和两个站点。没有确认、执行或完成按钮。新快照整体替换旧建议，站点过期时立即隐藏涉及它的建议。

## 历史 OD 回放

- 日期和小时由 availability 提供；默认最新可用日期、该日最早小时。更换日期先暂停，再选择该日最早小时。可用原生日期控件，但必须验证可用集合。
- 1x 每个业务小时播放 2 秒；0.5x/2x/5x 分别为 4/1/0.4 秒。倍速只控制展示节奏，不改变聚合数量；到当天最后可用小时自动暂停，不跨日循环。
- OD 按出发小时归桶；跨小时/跨日骑行在出发小时展示流向。站点流入曲线按到达小时计数，两者不能直接逐小时对账。
- 动画为站点间插值。坐标缺失的流向不绘制，并显示未绘制 OD 数量及骑行数，接口仍保留记录。忙碌时可减少装饰粒子，但图例和 ride_count 不变。
- Trip 无连续库存观测：库存、风险、预测、建议均不显示；历史状态胶囊标明“回放”，地图视角拨盘不提供实时风险与调度，不叠加今天的数据。历史站点透镜仍可用。
- 拖动小时只接受最后一次请求；模式、日期、小时切换后旧响应不能覆盖当前选择。已加载小时可在内存复用，不引入持久缓存系统。

## 站点地图透镜

默认展示所选星期的 24 小时 profile，流入/流出/净流量同图，显示基线覆盖日期与 sample_days。实时模式使用快照的纽约星期、小时；历史模式同时展示所选日期实际流量，并用其星期选择 profile。零值表示活跃日期/小时观察到零次，缺数据不补零；生成规则见 [数仓契约](contracts/warehouse.md)。

透镜锚定站点并覆盖局部地图，关闭后返回原地图视角和触发站点。名称/ID 搜索只定位已加载站点，不增加服务端搜索；无坐标站点的透镜居中显示且不伪造位置。

## 页面状态与验收

| 状态 | 页面行为 |
| --- | --- |
| 首次加载 | 显示加载提示，未返回前不显示零库存结论 |
| 200 + 空数组 | 对应业务空态，可继续更换日期/模式 |
| 400 参数错误 | 提示并恢复有效选择，不重复请求非法参数 |
| 404 未知站点/未发布日期 | 显示不可用，重新加载 availability |
| 422 结果超过界限 | 显示查询范围过大，不将截断结果冒充全量 |
| 503 或网络失败 | 标记同一选择的最近成功结果并提供重试；首次无缓存显示失败 |
| FIXTURE / GBFS_REPLAY | 始终显示“开发样例 / 录制快照”；历史 OD 回放另以 mode=replay 标识 |

可点击元素使用 button/input，具备键盘焦点与文字标签，风险不能只靠颜色区分。P1 的运营站点数、车辆数、空桩数、当前缺车数、当前满桩数从已返回的有效且可运营站点计算，历史模式不显示实时 KPI。

验收执行 [运行手册](runbook.md) 的五条 P0 路径及异常场景。Q1–Q4 于 2026-09-14/15 确认；2026-09-15 用户确认全部建议并授权完成剩余文档与分工，包含 Q5 异常处理。
