## Flume 日志进入 HDFS

从本轮已产生的 collector PUBLISHED 日志和 backend `operations published snapshot=` 日志各取一整行，作为不可变文件投入专用 spooldir。真实路径是 spooldir → file channel → HDFS，不是直接写 HDFS 冒充 Flume。

首次运行暴露 Flume 默认长行拆分：collector 单行超过 24 KB，HDFS 多出换行。设置 `sources.logs.deserializer.maxLineLength = 100000`，换新的输入文件名和目标目录重跑。旧失败产物保留，不混入通过证据。

最终 HDFS 路径：`/audit/citibike/integration-20260921-verified/runtime.*`。读回两行、25,161 字节，与输入逐字节相等，SHA-256 为 `6b665f3574dcd34241cc2ab32ba62fe87f9ff204a5a5bf66703d4a00cd325309`。本项证明真实日志经 Flume 落 HDFS，不宣称已经部署持续日志采集。
