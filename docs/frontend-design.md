# 棱镜空间前端设计

2026-09-17 用户选定棱镜空间作为正式方向。本文件取代旧圆形透镜、临时拨盘、暖白地图及浅色工作台的布局规范。旧高保真图片不再作为实现依据。视觉 token 见 [DESIGN.md](../DESIGN.md)，业务含义见[产品与交互](product.md)。HTTP 契约保持 v1.1。

## 页面结构

```text

│ 来源 · 观测时间                     │ 当前 / 预测 │ │
```

地图是主视图。右侧面板负责操作和解释，默认展示当前库存模式。页面不设大标题、宣传文案或运营 KPI 卡片。选定站点后，详情占用面板中的列表区域；返回可恢复搜索和列表上下文。状态说明按需展开，不遮挡关键地图操作。

## 地图

MapLibre 使用真实矢量街网与建筑挤出，默认紫银高倾角视图。地图支持拖动、缩放、复位与二维/三维切换。站点及业务线路按接口经纬度投影，移动视角后仍与地图对齐。无坐标站点可从列表打开详情，但不能补造位置。共享 fixture 只有两个站点，其坐标和名称按原样展示，不能为视觉密度伪造业务点。

城市光点与建筑扫描只提供视觉效果。准确库存、调度数量和 OD 数量另有独立图层与文字图例。地图服务不可达时显示重试入口，业务列表和接口状态仍可使用。署名不可被面板遮挡。

## 模式与路径

| 模式 | 面板 | 地图 |
| --- | --- | --- |
| 当前 | 风险排序、库存、搜索与站点详情 | 当前库存粒子与当前风险 |
| 预测 | 当前库存和一小时预测同时可读，显示基线样本与目标时间 | 库存数量保持不变，风险改用预测字段 |
| 调度 | 同批完整建议，选择后显示起终点、数量与直线距离 | 突出 Top 5 及选中路线，方向指向补车站 |
| 回放 | 可用日期、小时、播放、四档倍速、历史站点分析 | 只显示该小时非零 OD，移除全部实时业务图层 |

搜索按已加载站名或字符串 ID 匹配。方向键、Enter、Escape 可完成选择与返回。点击地图站点和列表站点进入同一详情；无坐标仍可分析。调度不提供执行、确认或完成按钮，路线不是道路导航。

## 站点详情

实时详情同时显示当前库存、空桩、容量、当前状态、预测值、预测状态、观测与目标时间。无效值使用缺失或异常说明，不能显示成零。过期数据以“上次观测”标明时间，并停止有效预测与调度。

24 小时历史图展示流入、流出、净流量、基线日期与 sample_days。回放详情同时支持所选日期的实际流量。没有基线和没有当日活动分别表达，缺小时不能补零连成伪曲线。曲线使用不同线型、文字图例和数值，不只靠颜色。

## 回放控制

日期与小时来自 availability。切换日期先暂停，再选择该日最早可用小时。0.5×、1×、2×、5× 在响应提交后分别等待 4、2、1、0.4 秒再播放下一个业务小时；到末小时暂停，不循环跨日。倍速改变展示时间，不能改 ride_count。

旧请求不能覆盖新选择。失败时保留上一个已成功的合法日期和小时并提示，不将旧地图挂在新时间标签下。无坐标 OD 保留接口记录，并显示未绘制条数和骑行数。

## 状态与恢复

| 情况 | 表达与操作 |
| --- | --- |
| 首次加载 | 加载提示，不预填零库存 |
| 成功但无站点/流量/建议 | 对应业务空态，保留模式与日期入口 |
| 首次请求失败 | 明确失败和重试，区分底图与业务接口 |
| 刷新失败 | 保留仍有效的最近结果并标记失败 |
| 已过期 | 隐藏有效库存粒子、预测和涉及该站的调度；详情可查看带时间的上次观测 |
| 无基线 | 保留有效当前库存；预测显示数据不足 |
| 负库存或停服 | 不画有效库存，不产生前端猜测的预测或建议 |
| 无坐标 | 列表和详情可用，地图不伪造锚点 |
| 参数/范围/日期错误 | 保留合法选择，说明不可用并提供恢复路径 |
| FIXTURE / GBFS_REPLAY | 始终显示开发样例或录制快照，不冒充实时 |
