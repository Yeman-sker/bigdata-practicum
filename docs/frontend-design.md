# 棱镜空间前端设计

2026-09-17 用户选定棱镜空间作为正式方向。本文件取代旧圆形透镜、临时拨盘、暖白地图及浅色工作台的布局规范。旧高保真图片不再作为实现依据。视觉 token 见 [DESIGN.md](../DESIGN.md)，业务含义见[产品与交互](product.md)。HTTP 契约保持 v1.1。

地图是主视图。右侧面板负责操作和解释，默认展示当前库存模式。页面不设宣传文案或运营 KPI 卡片墙；面板标题显示当前任务与站点数，站点详情顶部为 3 格紧凑指标。选定站点后，详情占用面板中的列表区域；返回可恢复搜索和列表上下文。状态说明按需展开，不遮挡关键地图操作。

## 地图

MapLibre 使用真实矢量街网与建筑挤出，默认紫银 58° 高倾角视图。地图支持拖动、缩放、复位与二维/三维切换。站点及业务线路按接口经纬度投影，移动视角后仍与地图对齐。无坐标站点可从列表打开详情，但不能补造位置。共享 fixture 只有两个站点，其坐标和名称按原样展示，不能为视觉密度伪造业务点。

按用户后续决定撤回视觉简化，恢复原站点标记、风险环、全部有效库存粒子、路线光点和标签，不再以聚合圆圈或近景选中门槛代替原表现。动效默认开启并尊重减少动态效果设置，装饰密度恢复为 1；光效开关直接显示在左侧工具条，密度滑块在工具条弹出层中。风险筛选仍由用户显式选择，选中站点及调度端点保留；筛选不改业务库存。全量站点密集与性能问题尚未重新解决，不将恢复外观等同于全量验收通过。

首次取得带坐标的数据自动归位一次，此后的快照、坐标元数据、筛选和模式更新不自动 fit。明确点击归位才重新展示全部站点；选择站点/建议仅在目标不可见或被操作面板遮挡时移动视角。

城市光点与建筑扫描只提供视觉效果。准确库存、调度数量和 OD 数量另有独立图层与文字图例。地图服务不可达时显示重试入口，业务列表和接口状态仍可使用。署名不可被面板遮挡。

## 模式与路径

| 模式 | 面板 | 地图 |
| --- | --- | --- |
| 当前 | 风险排序、全部/缺车/满桩/数据问题筛选、库存、搜索与站点详情 | 站点标记、当前库存粒子与风险环 |
| 预测 | 当前库存和一小时预测同时可读，显示基线样本与目标时间 | 库存数量保持不变，风险改用预测字段 |
| 调度 | 同批完整建议，选择后显示起终点、数量与直线距离 | 突出 Top 5 及选中路线，方向指向补车站 |
| 回放 | 可用日期、小时、播放、四档倍速、历史站点分析 | 只显示该小时非零 OD，移除全部实时业务图层 |

搜索按已加载站名或字符串 ID 匹配，和风险筛选共同作用于站点列表；风险筛选同步地图，已选站点/调度端点保留并注明。分页每页 50 站，显式显示范围/匹配总数，不丢弃记录。搜索方向键可以跨页，刷新保留活动站点 ID，详情返回保留查询、列表滚动与焦点。模式、搜索、筛选和状态固定在面板顶部；长列表与详情独立滚动。方向键、Enter、Escape 可完成选择与返回。点击地图站点和列表站点进入同一详情；无坐标仍可分析。调度不提供执行、确认或完成按钮，路线不是道路导航。

## 站点详情

实时详情同时显示当前库存、空桩、容量、当前状态、预测值、预测状态、观测与目标时间。无效值使用缺失或异常说明，不能显示成零。过期数据以“上次观测”标明时间，并停止有效预测与调度。

24 小时历史图展示流入、流出、净流量、基线日期与 sample_days。回放详情同时支持所选日期的实际流量。没有基线和没有当日活动分别表达，缺小时不能补零连成伪曲线。曲线使用不同线型、文字图例和数值，不只靠颜色。

## 回放控制

日期与小时来自 availability。切换日期先暂停，再选择该日最早可用小时。0.5×、1×、2×、5× 在响应提交后分别等待 4、2、1、0.4 秒再播放下一个业务小时；到末小时暂停，不循环跨日。倍速改变展示时间，不能改 ride_count。

日期选择器只列 availability 中有数据的日期；小时滑块使用可用小时索引，跳过不可用小时。拖动只更新预览，松开才提交，键盘改变即时提交；取消拖动恢复请求选择。请求新目标中止旧请求，旧请求的成功、失败及后续 availability 返回均不能覆盖新选择。

“已显示”时间来自成功响应，“请求中 / 失败目标”来自请求选择，拖动时另标“预览”。加载保留上次成功地图；失败暂停播放，保留失败目标和错误，重试请求该目标，不能回退控件后误重试旧小时。只有当前请求成功提交后才安排下一次播放，到末小时立即停止。

OD 默认恢复“全部”，保留“骑行量 Top 20 / 仅选中站点相关 / 隐藏”供用户主动筛选，不再默认截取 Top 20。筛选仅控制图上表达，完整列表与分母保留。显示可绘制条数/完整响应条数、可绘制骑行数/完整响应骑行数；可绘制表示过滤后且两端坐标齐全，不等于全部位于当前屏幕内。无坐标 OD 保留记录，另列缺坐标条数与骑行数；视图筛选不改业务分母。折叠的 OD 明细提供逐条起点→终点与精确骑行次数，每页 50 条且标明范围/总数；调度建议同样显式分页，保留全部记录。

## 状态与恢复

| 情况 | 表达与操作 |
| --- | --- |
| 首次加载 | 加载提示，不预填零库存 |
| 成功但无站点/流量/建议 | 对应业务空态，保留模式与日期入口 |
| 首次请求失败 | 明确失败和重试，区分底图与业务接口 |
| 刷新失败 | 保留仍有效的最近结果并标记失败 |
| 已过期 | 隐藏有效库存粒子、预测和涉及该站的调度；详情可查看带时间的上次观测 |
| 无基线 | 保留有效当前库存；预测显示数据不足 |
| 负库存或停服 | 不画有效库存，不产生前端猜测的预测或建议 |
| 无坐标 | 列表和详情可用，地图不伪造锚点 |
| 参数/范围/日期错误 | 保留成功地图及其显示时间，同时保留失败请求目标，明确原因并允许重试或另选可用时间 |
| FIXTURE / GBFS_REPLAY | 始终显示开发样例或录制快照，不冒充实时 |

## 验收

本轮按用户指定使用 Hermes native computer_use 在真实浏览器检查至少 1280×720 的五条 P0 路径、键盘焦点、模式隔离、预测不改库存、过期和请求失败、底图重试、减少动态效果及地图粒子对齐。截图和日志留在仓库外，实际结果写入 PR。构建与 fixture 通过不等于真实业务链路完成；真实全量数据、可读性、滚动/焦点和回放异常恢复须分别记录证据。
