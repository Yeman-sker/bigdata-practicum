# 前端交互与视觉设计

2026-09-16 按用户要求重设计。原有全屏地图、三个隐藏图标入口、圆形站点透镜和自动收起回放控件不再作为约束。实现位于 `frontend/`，使用 [DESIGN.md](../DESIGN.md) 的暖白、墨绿视觉规范。数据契约仍为 `1.1`。

## 工作台

顶部显示产品名称、数据模式、数据来源和状态。当前库存、未来一小时与调度建议使用可见文字入口。左侧为上下文面板，右侧为地图。上下文面板按当前选择显示站点列表、站点详情或调度列表。

站点列表支持站名和字符串 ID 搜索，按现有风险顺序排列，保留全部匹配站点。列表展示站名、ID、文字状态和有效库存。无坐标站点仍可进入详情，并标记“无法定位”。加载期间不把站点数或库存写成零。

地图底图保持低饱和度，站点、方向线与图例清楚可辨。地图容器、SVG 业务层与站点按钮共用坐标范围。列表滚动不移动地图，地图尺寸变化后重新同步投影。

## 实时与预测

当前视图显示实际库存与当前状态。未来一小时视图复用同一响应，只改变风险口径及相应文字，不改实际库存粒子。每个粒子表示一辆当前可用车，不代表单车 GPS。

缺车使用陶土色圆形标记，满桩使用赭色方形标记。异常使用中性色与状态文字。负库存、停服或过期记录不能画成有效库存；无基线仍可展示有效当前库存，预测显示不可用。

## 站点详情

点击站点列表或地图标记进入同一详情。左侧面板展示站名、ID、当前状态、实际车辆、空桩、一小时估计、观测时间与预测目标时间。原始有限预测值可为负数或小数，不按容量截断。

24 小时图表区分流入、流出和净流量，并标示当前小时。实时使用观测日对应星期的 profile；历史同时展示所选日期实际流量。显示样本日数与覆盖日期，无历史基线和当日无活动分别表达。历史请求失败提供局部重试。

关闭详情保留地图和筛选上下文，并将焦点返回可用的触发控件。长名称、错误文案和样本信息在面板内换行或滚动，不裁切关键值。

## 调度建议

调度列表展示同批全部有效建议。地图突出前五条，其余路线仍可选择。点击列表或路线选中同一建议，并显示来源、目标、车辆数、距离和预测依据。方向线从供车站指向补车站，不提供执行或完成按钮。

共享样例为样例乙站 `4199.12` 到样例甲站 `5484.09`，搬运 `8` 辆、距离 `84 m`。切换当前与未来视图不重新计算建议。建议或任一端点失效后清除相关路线与选择。

## 历史回放

进入历史先读取 availability，默认最新日期和该日最早可用小时。地图只显示历史 OD 和站点锚点，不叠加实时库存、风险或调度。来源、日期与小时保持可见。

日期、小时、播放或暂停、倍速在地图下方常驻。支持 `0.5×`、`1×`、`2×`、`5×`；`1×` 每个业务小时播放两秒，到当天最后可用小时暂停。切换日期先暂停，再选择该日最早可用小时。

非法日期或小时恢复上一个合法选择并解释原因。新请求失败时保留上一个成功回放，并使地图和控制器保持相同日期及小时。晚到的旧请求不能覆盖新选择。缺坐标的 OD 不绘制，并披露未绘制条数和骑行次数。

## 加载、空结果与恢复

| 状态 | 可见结果与操作 |
| --- | --- |
| 首次加载 | 显示加载提示，不显示业务结论或重复刷新操作。 |
| 首次请求失败 | 显示失败和重试，焦点进入重试按钮，不用 fixture 或零值伪装成功。 |
| 成功但结果为空 | 明确显示暂无站点、暂无可行建议或本小时无流量，保留相关模式或时间控件。 |
| 刷新失败 | 保留同一选择最近成功的数据，显示原时间及失败提示，提供重试。 |
| 数据过期 | 移除库存、预测与调度，保留中性站点锚点和上次观测信息，提供重试。 |
| 无基线 | 保留有效当前库存，预测不可用，详情解释暂无历史基线。 |
| 非法字段或停服 | 显示数据异常或服务不可用，不补零或标为健康。 |
| 无历史发布 | 明确显示暂无可用历史，不停留在加载态。 |
| `400`、`404`、`422` | 恢复合法选择，解释参数无效、站点或日期不可用、范围过大。 |

数据状态详情保留完整 dataset、baseline 与 snapshot 标识供核对。`FIXTURE` 始终标为“开发样例”，`GBFS_REPLAY` 始终标为“录制快照”。状态变化通过 `aria-live` 宣告。恢复后台页面时刷新当前数据。

## 键盘与验收

原生按钮与输入提供可见焦点和文字名称。搜索支持方向键和 Enter，`N` 与 `Shift+N` 巡览风险或异常站点，`[` 与 `]` 巡览调度。Escape 关闭详情或状态面板后恢复焦点。回放控件不因空闲而收起，减少动态效果不改变数据与播放节奏。

按 [runbook](runbook.md#五条-p0-验收路径) 验证当前库存、一小时风险、调度、历史回放与站点分析，并覆盖空数据、过期、失败恢复和无坐标状态。P0 桌面至少 `1280×720`。设计样张不代替运行中的浏览器验收；fixture 验证也不代表真实集群集成通过。

本轮不增加登录、司机执行流程、逐车 GPS、持久缓存、地图引擎依赖或独立组件库。P1 五项运营 KPI 继续延期，列表数量仅用于解释当前返回的站点或建议。
