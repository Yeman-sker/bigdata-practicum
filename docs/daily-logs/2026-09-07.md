## 实习记录

### 【今日实训主题与目标】
今日为生产实习第一天，由东软教育科技集团刘洪浩老师讲授。课程主要涵盖两大部分：
1. **大数据入门核心理论**：深入解析了 MapReduce 分布式计算框架的“分而治之”架构思想、Map 映射与 Reduce 归约阶段的工作原理，以及 Hadoop 生态圈全局架构（HDFS 存储、YARN 资源管理、Spark 内存计算、Hive 数仓分析等）；
2. **实训集群开发环境初始化**：明确了本次生产实习的 Linux 环境基线（Ubuntu 22.04 LTS），要求完成系统初始化与大数据软件包齐套校验。

### 【实操配置与执行过程】
根据课程实训要求，在本地开发机中拉起 Ubuntu 22.04.5 LTS (Jammy) 运行时环境：
1. **系统与网络初始化**：排查并修复了终端字符集（配置 LANG 及 LC_ALL 为 `en_US.UTF-8`），确保编译与日志输出不出现乱码。
2. **SSH 远程服务就绪**：安装并启动 OpenSSH 服务（`systemctl enable --now ssh`），调整 `sshd_config` 开放远程连接许可，并在防火墙放行对应端口。
3. **双 JDK 隔离策略落地**：为兼顾后续大数据组件与微服务构建，在开发机中落地双 JDK 隔离策略，分别部署 JDK 8 与 JDK 17 并配置快捷切换脚本（`use-jdk8.sh` / `use-jdk17.sh`）。
4. **大数据组件齐备性核验**：在 `/opt/soft` 目录下集中部署并核验课程所需核心安装包（Hadoop 3.3.6、Hive 3.1.3、Spark 3.5.7、Kafka 3.9.2、Flume 1.11.0、Sqoop 1.4.7 及 MySQL 驱动），完成底座开发环境的整体就绪。

### 【遇到的问题与排查解决】
1. **架构与依赖适配**：本地开发环境采用 macOS 宿主机配合 OrbStack 虚拟化（ARM64 架构），在核验 Hadoop 原生库时需要注意 aarch64 与传统 x86_64 预编译包的兼容性差异。通过配置统一的 JDK 8 环境并规划原生编译路径，规避了 NativeCodeLoader 异常。
2. **环境变量隔离**：由于后续 Spring Boot 3.x 及 Kafka 依赖 Java 17，而 Hadoop 3.3.6 生态必须运行在 Java 8 下，避免了直接在全局 `/etc/profile` 中硬编码单一 JAVA_HOME，改用 `source ~/use-jdk8.sh` 动态切换，经 `java -version` 核验证明运行环境纯净受控。
